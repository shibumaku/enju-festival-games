# 写真で場所当てクイズ

このプロジェクトは、写真を見てどこで撮られたかを4択で当てるブラウザゲームです。

## 使い方

1. `index.html` をブラウザで開きます。
2. 写真を見て、4つの選択肢の中から正しい場所をクリックします。
3. `次へ` をクリックして次の問題に進みます。

## 画像の差し替え

`script.js` の `questions` 配列にある `image` プロパティを、実際の写真 URL かローカル画像パスに変更できます。

例:

```js
{
  image: "images/tokyo.jpg",
  choices: ["東京", "大阪", "京都", "札幌"],
  answerIndex: 0,
}
```

## 拡張案

- 問題数を増やす
- 写真を自動読み込みする
- 正答率を保存する
- 地図や解説を表示する
